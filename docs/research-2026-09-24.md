# Native iOS client for Herdr (working name: Herdwick)

Research notes from 2026-09-24. Move them into the project repo once it exists.

## Herdr surface (verified locally against herdr 0.9.1, protocol 22)
- `herdr --session <s> remote-api-bridge` pipes stdio to the JSON API socket.
  Framing is newline-delimited JSON with one request per connection, e.g.
  `{"id":"1","method":"workspace.list","params":{}}`. `--check` prints
  `herdr-api-bridge-v1`. The bridge runs over a plain SSH exec, so it needs no
  streamlocal forwarding and no socat. Pure-Swift SSH (Citadel/NIO) works too.
- `ping` returns the version, the protocol number and capabilities.
  `session.snapshot` returns workspaces, tabs, panes and agents with
  `agent_status` (idle, working, blocked, done or unknown).
  `events.subscribe` (needs a `subscriptions` param) is a long-lived stream.
  `herdr api schema --json` returns the full JSON Schema: 121 requests and 26
  event types.
- Live terminal: `herdr terminal session control <pane> --takeover --cols N
  --rows M` streams `terminal.frame` NDJSON records with base64 ANSI, `seq`
  and `full`. Input comes back as `terminal.input`, `terminal.resize` and
  `terminal.release`. The first frame is `full:true`, so a reconnect repaints
  at once with no local replay. `observe` gives a read-only view.
- Input without a terminal: `pane.send_text`, `pane.send_keys` and `pane.run`
  (atomic, bracketed paste). `agent.prompt` submits text and waits.

## Competitors
- Heeler (App Store id6797263135, Apache-2.0, 403★) is the strongest. It uses
  libssh2 with direct-streamlocal, libghostty-spm for rendering, QR pairing
  through a herdr plugin, an encrypted push relay and Live Activities. It
  targets iOS 18 and ships no Tailscale integration.
- Herdie (id6807093029) attaches over SSH with a Rust core.
- herdr-ios (Volpestyle) uses SwiftTerm, requires Tailscale and drops the
  connection whenever the app is backgrounded.
- Herdi/herdr-remote uses a Python relay with a web UI.
- Differentiation: iOS 26 with Liquid Glass, in-app Tailscale sign-in with a
  machine picker, reconnect-first architecture, and simplicity.

## Tailscale (most seamless path)
- Embed TailscaleKit (github.com/tailscale/libtailscale/swift, official,
  BSD-3, active through 2026-08). It gives in-app userspace tailnet access and
  needs no VPN profile or Tailscale app.
- Login flow: watch for `browseToURL` and open it in an
  ASWebAuthenticationSession. The machine picker reads peers from
  `statusJSON()`, which survives iOS suspension (commit 8077131).
- `tailscale_dial` returns a POSIX fd. SwiftNIO should be able to adopt it
  through `withConnectedSocket` and run SSH over it [INFERENCE: spike].
- If the target runs Tailscale SSH, key management disappears (`none` auth).
  Otherwise the app generates an Ed25519 key and offers a copy-paste
  authorized_keys line.
- Fallback: plain host, IP or domain works when the user runs the Tailscale
  VPN app.
- Risks: binary size, and every phone appears as a tailnet node.

## Reconnect design
- On background, the app closes cleanly. On foreground (scenePhase) or an
  NWPathMonitor change, it reconnects right away without waiting for TCP
  timeouts, and shows the cached snapshot dimmed in the meantime.
- SSH keepalive every ~10 s in the foreground. Backoff stays short and
  capped. Race the direct route against the tailnet route.
- Server state plus a full-frame resync makes mosh unnecessary.

## Build host
- Xcode 27.0 is current. It needs macOS 26.6 or later; the Mini ran 26.5.1
  with about 11 GiB free after pruning, so Xcode lives on the E0 APFS SSD.
- Linux via xtool builds SwiftPM apps but has no simulator or previews, needs
  Xcode.xip anyway, and cannot build TailscaleKit (which needs the Apple
  toolchain). Use the Mini, driven over SSH from nous.
- Signing: team 7F3KV9WTNW (Developer ID exists on the MacBook). Headless
  signing and TestFlight upload through an App Store Connect API key.

## Name
- A Fable council checked App Store, GitHub and ecosystem conflicts. The
  Shepherd family is blocked: shepherd.js, shepherd-agents, shepherdr in the
  herdr ecosystem, and 12+ App Store titles.
- Consensus: Herdwick. It is clear on the App Store and GitHub, and the
  herdwick.app/.dev RDAP lookups returned not found. Hird is the runner-up,
  but hird.app/.dev are taken. Shieling and Steading are also clear.
