Herdwick is a client for herdr, open-source software (Apache-2.0, github.com/herdrdev/herdr) that developers run on their own Mac or Linux machine to host terminal sessions for coding agents. Herdwick connects to that machine over SSH, lists the agents herdr tracks, shows a pane's live terminal and sends replies. There is no account and no server operated by the developer.

HOW TO REVIEW WITHOUT A MACHINE
On the first screen, tap "No machine handy? Explore a demo host". This opens a scripted herdr host built into the app, so every screen can be reached without SSH access:
1. Agents: agents grouped by Needs you, Done, Working and Idle. Switch to Workspaces with the segmented control.
2. Tap "Deploy to staging" (Needs you). The pane shows the agent's terminal with a question.
3. Type a reply in the Message field (for example "Run the migrations first, then deploy") and tap Send. The agent moves to Working, then Done.
4. The key bar above the composer sends Esc, Tab, arrows, Enter and Ctrl-C. The keyboard button takes over typing.
5. The gear button opens Settings: appearance, terminal themes, font, haptics.
6. The host menu (top left) has "Leave Demo" to return to the first screen.

REAL CONNECTIONS
- Address: SSH to any host running herdr, using a key generated on the device (shown in Settings to add to authorized_keys) or a password.
- Tailscale: optional. It needs the reviewer's own Tailscale account and a machine on that tailnet; the embedded Tailscale client (libtailscale) runs inside the app and does not install a VPN profile. The Address path covers the same features.

PERMISSIONS AND DATA
Network access only. SSH keys and passwords are stored in the iOS Keychain on the device. No analytics or tracking. Terminal content goes directly between the device and the user's machine.

Herdwick is an independent project, not affiliated with the herdr project or Tailscale Inc.
